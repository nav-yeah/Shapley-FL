# Shapley-FL

Shapley-value contribution scoring for federated learning on the UCI HAR dataset, with Shapley-weighted aggregation, Byzantine drift detection, and a blockchain audit.

## Layout

```
Shapley-FL/
├── src/                   all Python scripts (they import each other, so keep them together)
├── results/
│   ├── p1_shapley/        Shapley scores and scenario results
│   ├── p2_aggregation/    aggregation, fairness, FedProx and Dirichlet results
│   └── p3_detection/      Byzantine detection outputs
├── docs/                  working notes and writeups
├── paper/                 final paper
├── tests/
├── p4_blockchain-audit/   Solidity/Hardhat audit (see p4.md)
├── preprocessed/          generated by preprocess_har.py (git-ignored)
└── scenarios/             the 5 scenario .pkl files
```

## Setup

```
pip install -r requirements.txt
```

See `docs/SETUP_AND_HANDOFF.md` for dataset setup.

## Running

Run every command from the repository root.

- **Stage 1 (Shapley):** `preprocess_har.py`, `exact_shapley.py`, `gtg_shapley_approx.py`, `build_scenarios.py`, `run_scenarios.py`, `export_shapley_csv.py`
- **Stage 2 (aggregation):** `shapley_weighted_fedavg.py`, `jains_fairness.py`, `plot_convergence.py`, `fedprox_compare.py`, `dirichlet_alpha_sweep.py`
- **Stage 3 (detection):** `p3_byzantine_detection.py`

Example: `python src/shapley_weighted_fedavg.py`. Details are in `docs/P2_RUN_ORDER.md`.
