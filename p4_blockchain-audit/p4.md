# P4 — Blockchain Audit and Verification

## Platform choice

The blockchain audit uses Ethereum smart contracts written in Solidity. The contracts were tested on a local Hardhat network and deployed to the Sepolia testnet.

The historical 150-entry local Hardhat run is documented separately from the later 1,500-entry Sepolia verification. These runs use different environments and datasets, so their gas measurements and verification results should not be treated as directly interchangeable.

## Historical local Hardhat run (150 entries)

The local Hardhat run used the merged synthetic detection dataset containing 150 entries (30 clients × 5 rounds), including 30 flagged rows.

### Historical results

- **150 entries** logged.
- **30 of 150 rows flagged**.
- The local contract recorded the detection results and emitted events for flagged entries.
- The local run produced `gas_report_local_150.json` and `enforcement_report.json`.

These results describe the historical local run only; they are not the results of the later Sepolia verification.

## Outputs

- `deployed-address.json` — recorded local deployment address.
- `gas_report_local_150.json` — total and average gas per logged entry, with a per-row breakdown.
- `enforcement_report.json` — per-client flagged/clean counts and eligibility.
- `verification_summary_corrected.json` — corrected Shapley contract verification summary.
- `verification_original_source_summary.json` — comparison against the original detection and Shapley source data.
- `gas_report_sepolia.json` — consolidated gas report for the detection contract.
- `gas_report_corrected_sepolia.json` — consolidated gas report for the corrected Shapley contract.

## Gas usage discrepancy between the Sepolia contracts

The recorded per-entry gas values differ substantially between the two deployed contracts:

- **Detection contract (`0xA7694F641937687Af7D09a314Ee0fb828c1F78Fe`):** approximately 175,000–229,000 gas per entry.
- **Corrected Shapley contract (`0x45E4a0f7933A56D8a30288039c883d36F768CC27`):** approximately 710,901–1,014,757 gas per entry.

The cause of this difference has **not been established** by the available repository evidence. The files in `contracts/` have not changed since the original commit, so the discrepancy should not be attributed to a contract code change without further evidence.

Possible factors to investigate include differences in executed transaction paths, inputs, deployment or execution conditions, and how gas values were collected or consolidated. These remain hypotheses, not confirmed explanations.

The consolidated reports also contain totals that differ from previously recorded measured-run totals. Consequently, the consolidated per-entry values should not be assumed to represent one controlled, consistently measured run until the underlying transaction receipts and reporting conditions have been reconciled.

## Reproducibility and report scope

- `gas_report_local_150.json` documents a local Hardhat run with 150 entries.
- `gas_report_sepolia.json` documents gas information associated with the detection contract on Sepolia.
- `gas_report_corrected_sepolia.json` documents gas information associated with the corrected Shapley contract on Sepolia.
- `verification_summary_corrected.json` records the corrected 1,500-entry verification with zero mismatches.
- `verification_original_source_summary.json` records the comparison against the original source datasets, including the rate-limit qualification.

The local Hardhat gas measurements and Sepolia reports come from different environments and runs. They should be reported separately and not combined into a single gas benchmark without reconciling their underlying transactions and measurement methods.

The synthetic CSV inputs are tracked in version control for clean-checkout reproducibility. The 1,500-entry enforcement report has not been marked as verified for that run unless and until its provenance and results are confirmed.
